# Day 01 – Personal Website

## Assignment Overview

For the first assignment, I created a personal website using GitHub Pages with the help of ChatGPT.

The goal was to introduce myself, share my academic background and research interests, and practice using GitHub and AI tools for web development.

## What I Did

1. Created a GitHub repository named `danigeller.github.io`.
2. Used GitHub Pages and Jekyll to publish my website.
3. Created the website content using Markdown, including sections about my academic background, research, and hobbies.
4. Customized the website's appearance using CSS.
5. Used ChatGPT to help with coding, troubleshooting, and generating illustrations.
6. Published the website and checked that it was working.

## Using AI

I used ChatGPT throughout the assignment to help me develop and improve my website.

Examples of prompts and requests I used include:

* Help me create a personal website using GitHub Pages.
* Change the fonts to create a more artistic appearance.
* Help me adjust the layout and image sizes.
* Help me troubleshoot GitHub Pages deployment issues.

## Tools Used

* GitHub and GitHub Pages
* Jekyll
* Markdown
* CSS
* ChatGPT
