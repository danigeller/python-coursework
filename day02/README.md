# Day 02 – Assignment

In this assignment, I installed Python and used Visual Studio Code to write and run my first Python program.

## Steps

1. Installed Git, Python, and Visual Studio Code.
2. Created a GitHub repository called `python-coursework`.
3. Cloned the repository to my computer using VS Code.
4. Created a folder called `day02` and a Python file named `first_code.py`.
5. Wrote the following code:

```python
print("Hello, world!")
```

6. Ran the program in the VS Code terminal using:

```bash
python day02/first_code.py
```

The output was:

```text
Hello, world!
```

7. Committed the changes and synced the repository with GitHub.
